# AttenCheck

**4時間ハッカソンで制作した、人間中心の集中状態可視化プロトタイプ**

- 制作日：2025年12月21日
- 制作人数：3名
- 結果：2位
- 開発状態：当日制作版・開発終了
- 使用技術：Python / MediaPipe / OpenCV / Streamlit / Firebase（試行）/ Blender

## 背景と目的

AttenCheckは、授業やコミュニケーションの場における「相手の反応が見えない」という課題から生まれました。

単なるサボり検知や監視ではなく、場の状態を抽象的に共有し、指導者が状況を把握するための支援ツールを目指しました。

## 当日に実現したこと

- カメラ映像からの顔検知
- 集中度に応じた画像を表示する管理者画面のデモ
- 本や植物の3D表現を用いた視覚化の提案
- 作品の目的・技術構成・将来構想のプレゼンテーション

顔検知と管理者画面は別々のウィンドウで実演しました。

## 未完成の機能

顔検知結果を用いた集中度の自動算出と、その結果を管理者画面に反映する一連の処理は、時間内に完成しませんでした。

また、画像を送信せず解析結果のみを共有する通信設計は、当時の構想であり、完成済み機能ではありません。

## チームと担当

3人で制作し、以下のように分担しました。

- 顔検知・AI機能の開発：本人
- アプリケーションの枠組み：チームメンバー
- 3Dモデル・レンダリング画像：チームメンバー

企画、実装、発表資料作成までを当日の約4時間で進めました。

## 成果

完成したシステムとしての動作実証には至りませんでしたが、実装済み機能と今後の構想を分けて発表し、2位を獲得しました。

このリポジトリには、当時の試作コードや実験用ファイルが含まれています。すべてのファイルが完成済み・動作確認済みであることを意味しません。
